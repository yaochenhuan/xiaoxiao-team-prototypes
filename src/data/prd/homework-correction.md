## 1\. 需求背景

### 1\.1 业务背景

当前学生在平台完成课后作业后，系统仅提供标准答案对照和得分展示，缺乏针对错题的闭环学习机制。学生通常无法系统性地完成"错误原因分析→笔记总结→错题订正练习"的完整学习流程，导致同一知识点反复出错、学习效果难以持续提升。

为此，引入**作业订正功能**，覆盖三种订正入口和四步订正闭环（题目讲解→确认错误归因→总结笔记→订正练习推送），通过 AI 助教辅助和手动补充两种模式，实现错题的系统性学习与巩固。

### 1\.2 用户痛点

|编号|痛点|说明|影响程度|
|---|---|---|---|
|PA\-01|错题没有学习闭环|学生只看对错，不看原因，不记笔记，不练同类题|高|
|PA\-02|错误归因靠自我感知|没有引导，学生说不出做错的原因，无法针对性改进|高|
|PA\-03|笔记分散、缺乏分类|现有笔记只有"我的笔记"一种类型，不支持订正笔记的独立管理|中|
|PA\-04|老师无法追踪订正进度|现有作业详情只有"完成状态"，无法判断学生是否订正了错题|中|
|PA\-05|同类题练习缺少入口|现有巩固训练只支持精听、精读、单词，缺少订正类练习|中|
|PA\-06|学生订正入口不清晰|没有明确的引导，学生不知道在哪里开始订正|中|

### 1\.3 用户故事

**学生端（共 8 条）：**

|编号|用户角色|场景|目标|验收标准|
|---|---|---|---|---|
|US\-01|学生|刚提交作业，想立即订正|系统弹窗引导，进入订正流程|提交后弹窗，点击即进入订正页，自动打开 AI 助教|
|US\-02|学生|在结果页查看错题，想订正|在结果页找到入口进入订正|结果页有"订正"按钮，点击进入订正页（仅错题）|
|US\-03|学生|通过 AI 助教自由对话订正|自然语言描述需求，AI 辅助完成|在结果页打开 AI 助教，可直接说"帮我总结这道题的笔记"，AI 总结后保存为订正笔记|
|US\-04|学生|手动添加订正笔记或修改错误归因|不依赖 AI，手动完成订正|在结果页手动添加订正笔记或修改错误归因，即视为该题已订正|
|US\-05|学生|订正过程中让 AI 讲解题目|听不懂时让 AI 一步步讲解|AI 自动讲解当前题目，学生点击"完成讲解"进入下一步|
|US\-06|学生|确认/修改系统总结的错误归因|快速确认或自定义归因|系统先总结归因，学生点击"确认"或"不太对"后选择其他原因，也可直接输入|
|US\-07|学生|总结订正笔记|系统生成笔记，学生修改后提交|系统按 3 步法生成笔记，学生可提交、修改或重新输入|
|US\-08|学生|订正完成后做同类题练习|巩固知识点，避免重复犯错|订正完成后推送同类题，跳转巩固训练完成练习|

**老师端（共 1 条）：**

|编号|用户角色|场景|目标|验收标准|
|---|---|---|---|---|
|US\-09|老师|查看班级作业订正情况|了解每个学生的订正进度|作业详情页新增"订正状态"和"订正练习"列，可查看学生的订正和练习完成情况|

### 2\.2 三种订正形式详解

#### 形式一：作业结果页/错题结果页进行 AI 助教问答（结构化订正）

```
学生提交作业
    ↓
    ─→ 进入结果页
             ↓
            打开 AI 助教→ 点击"题目讲解"
                    ↓
            ① 题目讲解 → ② 确认归因 → ③ 总结笔记 → ④ 推送练习
                    ↓ 所有错题订正完
            提示"完成订正，去做练习吧" → 点击[开始练习] → 巩固训练         

```

#### 形式二：结果页 AI 助教自由问答（自由模式订正）

```
结果页 → 打开 AI 助教面板
    │
    ├─→ 自然语言对话（如"帮我总结这道题的知识点"）
    │    ↓
    │    AI 生成笔记 → 自动保存为订正笔记 → 该题已订正
    │
    ├─→ 点击快捷按钮「题目订正」→ 进入四步结构化流程
    │
    └─→ 任意操作（讲解、归因、笔记、练习）均可随时触发
```

#### 形式三：结果页手动添加笔记（手动订正）

```
结果页 → 某道错题 → 手动添加订正笔记入口
    │
    ├─→ 输入笔记内容 → 保存 → 该题已订正
    │
    └─→ 手动修改错误归因 → 选择/输入原因 → 保存 → 该题已订正
```

#### 4\.2\.2 功能说明

**状态计算规则：**

|状态字段|计算规则|显示位置|
|---|---|---|
|订正状态（作业级别）|未订正：所有错题的订正状态 = 未订正；订正中：至少一道错题订正中/已订正但不是全部；已订正：所有错题的订正状态 = 已订正|页面顶部|
|订正练习状态|未开始：未打开订正练习；进行中：已打开练习但未提交；已完成：已提交订正练习|页面顶部|
|订正状态（题目级别）|未订正：该题未填写订正笔记、未修改归因、未做练习；已订正：该题填写了订正笔记或修改了归因或做了练习|左侧题目列表|

**手动订正入口：**

- 仅对错误题目显示「添加订正笔记」和「修改错误归因」按钮

- 点击「添加订正笔记」→ 弹出笔记输入弹窗/面板 → 输入后保存 → 该题订正状态变为已订正

- 点击「修改错误归因」→ 弹出错误归因选择面板 → 选择或输入后保存 → 该题订正状态变为已订正

**左侧题目列表改造：**

- 在错误题目（学生答案 ≠ 正确答案）的列表项上，右侧新增订正状态标签

- 标签样式："未订正"为橙色/红色标签，"已订正"为绿色标签

- 已订正的题目也可以点击重新订正（补充笔记或修改归因）

## 5\. 数据规则

### 5\.1 订正状态（题目级别）

|状态值|说明|判定条件|
|---|---|---|
|**未订正**|该题目尚未开始订正|该题目未填写订正笔记、未修改错误归因、未做订正练习|
|**订正中**|该题目正在订正过程中|该题目已开始订正（如已讲解但未确认归因）|
|**已订正**|该题目已完成订正|该题目填写了订正笔记 **或** 完成了订正练习|

> **判定规则说明：** 两种条件满足任一即视为已订正。
> 
> 

### 5\.2 订正状态（作业级别）

|状态值|说明|判定条件|
|---|---|---|
|**未订正**|该作业所有错题均未订正|所有错题和主观题的题目级别订正状态 = 未订正|
|**订正中**|该作业部分错题已订正|至少一道错题已订正或订正中，但不是全部|
|**已订正**|该作业所有错题均已订正|所有错题的题目级别订正状态 = 已订正|

### 5\.3 订正练习状态（作业级别）

|状态值|说明|判定条件|
|---|---|---|
|**未开始**|订正练习已生成但未开始|订正练习组卷已生成，学生未打开练习页面|
|**进行中**|已开始答题但未提交|学生已打开练习页面并开始答题（至少答了一题）|
|**已完成**|已提交订正练习|学生已提交订正练习答卷|
|**—**|无订正练习|作业无错题或练习未生成|

> **状态流转：** 未开始 → 进行中（学生打开并开始答题）→ 已完成（学生提交答卷）。进行中 → 未开始（学生打开但未答题，关闭页面，状态保持进行中，不重置）。
> 
> 

### 5\.5 笔记类型

|类型|说明|创建方式|关联关系|可删除|
|---|---|---|---|---|
|**练习笔记**|学生在练习/做题过程中记录的笔记|手动创建|关联题目|是|
|**订正笔记**|订正过程中由 AI 助教提交或学生手动录入的错题笔记|AI 助教提交（四步流程第 3 步）或手动添加|关联题目|是，但删除后可能影响订正状态|
|**公开笔记**|公开分享的笔记，其他学生可见|手动创建并设置公开|可关联题目或独立|是|
